# Restricted or governed data

No restricted data files belong in this public directory. The following must not be included in public Zenodo packages:

- farm-boundary and management-polygon geometries;
- direct farm or participant identifiers;
- private Google Earth Engine assets;
- credentials, tokens, API keys, or request identifiers;
- raw/local Sentinel-2 products when redistribution terms are unclear;
- USGS auxiliary files if redistribution is not authorized;
- source documents whose copyright or distribution permission is not established.
