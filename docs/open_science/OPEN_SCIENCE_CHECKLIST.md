# Open Science pre-release checklist

## Identity and citation

- [ ] Name is consistent across manuscript, CFF, CodeMeta, and Zenodo.
- [ ] ORCID is added and verified.
- [ ] Corresponding-author email is confirmed.
- [ ] Git repository URL is recorded.
- [ ] Zenodo DOI is reserved and inserted.

## Data governance

- [ ] No farm geometries or direct identifiers are included.
- [ ] No credentials, API keys, request IDs, or private asset paths are included.
- [ ] Derived tables contain no disclosive identifiers.
- [ ] Third-party redistribution rights are reviewed.

## Reproducibility

- [ ] Final analysis scripts are present.
- [ ] Observation-level input for Figure 4 is present or documented as restricted.
- [ ] Seeds and bootstrap settings are documented.
- [ ] Container tag and immutable digest are recorded.
- [ ] Python/R/system inventories are captured.
- [ ] Five final figures are present and legible.
- [ ] Manuscript renders from a clean checkout.

## Publication hygiene

- [ ] Placeholder MDPI DOI is removed.
- [ ] Internal author-action comments are removed.
- [ ] Legacy and backup files are excluded from public packages.
- [ ] Checksums are current.
- [ ] Zenodo preview is reviewed before publication.
