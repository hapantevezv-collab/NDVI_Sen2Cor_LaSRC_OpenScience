# File naming convention

Use lowercase ASCII names for new machine-facing assets where practical:

- `article.qmd`, `references.bib`
- `fig01_study_area.png`
- `fig02_workflow.pdf`
- `table_agreement_three_pipelines.csv`
- `table_gradient_land_use.csv`

Existing manuscript filenames are retained when required by the current rendering workflow. Avoid spaces, parentheses, duplicate suffixes such as `(1)`, and ambiguous labels such as `final`, `final2`, or `VF`. Use semantic versions for public releases.
