# Code curation status

The public `code/analysis/` and `code/figures/` directories contain a curated subset with English filenames. Historical scripts, backup notebooks, manuscript-editing utilities, and superseded figure versions are preserved under `local_only/archive/legacy_code_*` and are excluded from public packages.

Before version 1.0.0, each curated analysis script must be checked for parameterized input paths, English documentation, and end-to-end reproducibility.
