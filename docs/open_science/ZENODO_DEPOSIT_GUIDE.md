# Zenodo deposit guide

1. Run the public-release audit.
2. Confirm that all package checksums pass.
3. Reserve the Zenodo DOI only after title, creators, ORCID, licenses, and record relationships are final.
4. Upload software, dataset, and manuscript as separate records, or use the compendium package as a single-record alternative.
5. Do not upload `local_only/`, restricted geometries, credentials, private Earth Engine assets, or absolute workstation paths.
6. Add the reserved DOI to citation metadata and rebuild the final release before publication.
